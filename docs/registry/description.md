## Complete SEO Toolkit for EmDash

QuixSEO by EmQuix helps you review content, improve search appearance and manage technical SEO from your EmDash admin. Free and open source under the MIT license, with no plugin account, paid features, ads or external AI calls.

### Plan, review and improve

- Analyze saved content and explicitly check unsaved editor changes, with SEO and readability guidance, focus keyphrases and search previews.
- Save cornerstone flags, additional robots directives, Open Graph and X overrides, and validated structured data.
- Run published-content audits with automatic progress when the host scheduler is configured. Review duplicate SEO metadata, link counts and potential orphaned pages.
- Find related internal-link opportunities, review plugin-owned bulk changes and roll back eligible changes.
- Manage exact-path redirects and preview mapped Yoast/Rank Math imports.
- Optionally generate llms.txt content, with preview, download and a documented host route.

### Built around native EmDash SEO

EmDash owns SEO titles, descriptions, canonicals, the main social image and noindex. Edit those in its native SEO panel; QuixSEO reads them for analysis. Native SEO bulk writes and imports are preview-only on the tested sandbox bridge.

Scores are editorial guidance, not ranking predictions. Link analysis covers published content; it does not crawl navigation menus or external backlinks. The optional llms.txt feature does not guarantee AI discovery or citations.
