### Is QuixSEO free?

Yes. There are no paid features, advertising or required plugin accounts. Hosting costs are separate.

### Where do I edit my SEO title and description?

Use EmDash's native SEO panel. QuixSEO analyzes those values; native SEO bulk edits and migration writes are preview-only on the tested bridge.

### Why is there a separate save button?

Use **Save QuixSEO settings** for keyphrases, cornerstone, additional robots flags, social overrides and schema. The ordinary EmDash Save does not save pending QuixSEO settings.

### Can it analyze unpublished changes?

Yes. The saved-entry panel identifies saved unpublished changes. The explicit current-editor analysis checks an unsaved snapshot without publishing it. Public metadata does not use unpublished body changes.

### Does it send content to AI or track visitors?

No. QuixSEO has no external AI calls, outbound network requests or visitor analytics tracker.

### Does a high score guarantee rankings?

No. Scores summarize the checks that could run. Review coverage and unavailable checks; schema does not guarantee rich results.

### Does it replace sitemaps or robots.txt?

No. EmDash owns native sitemaps and indexing controls. The optional llms.txt output needs a host route and does not modify robots.txt.

### Can I undo changes?

Eligible plugin-owned bulk/import changes support conditional rollback while current values still match the change record. Native fields and redirects are outside that journal. Back up before migration.

### Can I run another SEO plugin?

Use one owner for overlapping metadata and schema. Analysis can run with QuixSEO's output disabled. Full compatibility with other SEO plugins is not verified.
